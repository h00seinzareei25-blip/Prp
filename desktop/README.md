# نسخه دسکتاپ (فایل اجرایی ویندوز) با دیتابیس مجزا

این پوشه، برنامه تک‌فایلی `Prp100 .html` را به یک برنامه دسکتاپ تبدیل می‌کند که داده‌ها را
در یک **فایل دیتابیس مجزا** نگه می‌دارد، نه در حافظه داخلی مرورگر.

## داده‌ها کجا ذخیره می‌شوند؟

فایل اصلی دیتابیس:

```
PRP-Data/prp-database.json
```

- **نسخه Portable:** پوشه `PRP-Data` کنار خود فایل exe ساخته می‌شود؛ کل پوشه را کپی کنید تا داده‌ها هم منتقل شوند.
- **نسخه نصبی:** اگر پوشه نصب قابل نوشتن باشد کنار برنامه، در غیر این صورت در `%APPDATA%\PRP-Clinic-Manager\PRP-Data`.
- **مسیر دلخواه (مثلاً درایو شبکه یا فلش):** متغیر محیطی `PRP_DATA_DIR` را تنظیم کنید.

نکات مهم ذخیره‌سازی:

- هر بار ذخیره، ابتدا در فایل موقت نوشته و `fsync` می‌شود و سپس جایگزین فایل اصلی می‌گردد؛
  پس قطع برق در میانه ذخیره‌سازی، دیتابیس را ناقص نمی‌کند.
- نسخه‌های پشتیبان خودکار در `PRP-Data/backups` نگه داشته می‌شوند (حداکثر ۳۰ نسخه).
- اگر فایل دیتابیس خراب باشد، برنامه آن را با پسوند `corrupt` کنار می‌گذارد و آخرین پشتیبان سالم را بازمی‌گرداند.
- تنظیمات جزئی که برنامه در `localStorage` نگه می‌دارد نیز داخل همان پوشه (`PRP-Data/app-state`) ذخیره می‌شود.

از منوی **دیتابیس** داخل برنامه می‌توانید پوشه داده‌ها را باز کنید، پشتیبان فوری بگیرید و مسیر فایل را ببینید.

## اجرا در حالت توسعه

```bash
cd desktop
npm install
npm start
```

## ساخت فایل exe

ساخت خروجی ویندوز باید روی **ویندوز** انجام شود (یا روی لینوکس با نصب wine).
روی ویندوز با Node.js نسخه ۲۰ یا بالاتر:

```bash
cd desktop
npm install
npm run build:win
```

خروجی‌ها در پوشه `desktop/dist`:

| فایل | توضیح |
| --- | --- |
| `PRP-Portable-1.0.0.exe` | تک‌فایل قابل حمل؛ بدون نصب اجرا می‌شود و داده‌ها را کنار خودش می‌سازد |
| `PRP-Setup-1.0.0.exe` | نصب‌کننده با امکان انتخاب مسیر نصب و ساخت شورتکات |

برای ساخت فقط نسخه Portable:

```bash
npm run build:win-portable
```

### آیکون برنامه

برای آیکون اختصاصی، فایل `build/icon.ico` (اندازه ۲۵۶×۲۵۶) را قرار دهید و دوباره build بگیرید.

## آزمایش

```bash
npm test          # روی ویندوز
xvfb-run -a npm test   # روی لینوکس بدون نمایشگر
```

این آزمون برنامه را با یک پوشه داده موقت اجرا می‌کند، یک بیمار ثبت می‌کند، نوشته‌شدن آن را
در فایل دیتابیس بررسی می‌کند و پس از بازخوانی برنامه، بازگشت همان داده را تأیید می‌کند.

صحت تنظیمات بسته‌بندی با ساخت خروجی لینوکس (`npm run build:linux`) آزمایش شده است؛ خروجی ویندوز
با همان تنظیمات ساخته می‌شود و فقط به محیط ویندوز (یا wine) نیاز دارد.

## نسخه مرورگر

فایل `Prp100 .html` مستقل باقی می‌ماند: اگر پوسته دسکتاپ حاضر نباشد، برنامه مثل قبل از
IndexedDB مرورگر استفاده می‌کند و هیچ رفتاری تغییر نمی‌کند.
